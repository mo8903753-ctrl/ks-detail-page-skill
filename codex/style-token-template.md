# style-token 模板（项目层填色,法则通用）

## 项目层(每案必填)
主色/底色/强调色/禁色: ____　字体: ____(全站统一,三档字重)　明暗配比: ____(如明60暗40)

## 通用法则(直接继承)
- v整体感:一帧一巨物;禁圆角卡贴纸/图标格;引线标注;产品语言做骨架
- v材质法:"尺寸可以喊,材质必须闭嘴"——平涂锐边,禁字内纹理/3D字/金属牌/粒子/bokeh底纹;徽标=平涂胶囊或1px描边
- v声量分级:A巨字帧全站≤10只给区块开场/B画面主导/C静帧;相邻不同档
- v明暗双域:每KSP=暗开场→明证明;明域帧产品必须有真实表面与投影,禁真空白底悬浮渲染
- v节奏律:子链内明开暗收,禁明暗zigzag
- v烧字单位:mm小写连写;字表外零烧字
- v100%窗:合焦取样/禁人脸/字节级原值/1px主题色硬边/底图不与他处重复
