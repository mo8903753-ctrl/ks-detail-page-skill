# 结构语法（通用）

## 五卖点漏斗（排序逻辑）
资格(能不能用/兼容) → 角色(用来干嘛/场景定位) → 价值(核心技术差异) → 独占(别人做不到的) → 体验(用着舒不舒服)。
最重的技术主张放第3位：读者已被钩住、注意力未衰减。核心大数字禁止在 KV 抢跑——留给所属区首曝。

## 区内四层结构（每个卖点区一律）
1. 宣言层：暗域 A 档开场/巨字海报（一区至多一张巨字）
2. 图示层：渲染图/图解/参数标注——讲主张与原理
3. 实拍层：该主张对应的真实样张/实拍 GIF——作证收尾
4. 原生解释层：KS 原生文字事实段（图讲说服、字讲原理与边界）
图示与实拍禁止穿插排列；样片按"它证明什么"归队，不按好看乱放。

## 子卖点链
- 标题含双承诺的区按承诺拆链（如"量与质"：主参数给量、支撑参数保质）
- 每条链 = 小标题(收益前置+参数) + 一句解释段 + 1-3 个证物
- 明开暗收节奏律：链内浅底图示开场 → 暗调实拍/GIF 收尾，禁链内明暗 zigzag
- 每个子承诺至少一个可见证物；"反复声称、从不证明"= 结构性缺陷

## 诚实边界条款
产品的已知限制主动讲（放在对应卖点区内，紧跟主张），配图示或原生文字。不讲会在评论区被处刑；自己讲是专业感。

## 全局节奏
- 相邻帧不同声量档（巨字帧全站≤10）；同版式帧禁相邻（尤其区尾+下区开场）
- 全家福/同题材帧全页≤1处主讲；桌面摆拍全站≤3帧
- 口号收拢：一句主口号贯穿，禁多口号并行稀释；同句口号全页只出现一次
