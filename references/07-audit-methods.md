# 审计与验收工法（Claude 端·到成品交付为止）

## 逐帧证明力审计（workflow 并行）
每帧对照本区标题问："这张图证明了标题承诺吗？" match_score 1-5(5=直接证明;3=气氛相关不证明;1=无关)。
≤3 必写 problem + better_home(挪去哪区) + replacement_idea。同时扫风格重复(连续黑底转台类)。
产出=调仓令(挪位)+换血令(换素材)+重做令(重生成)三张清单。

## GIF 验收
见 03-gif-rules 自检项，验收方逐帧独立复扫(黑边/红标/运动量/内容 vs 字表)。

## 比例复测
像素测量法：分色检测(暗色/主题色分开)防轮廓与线连成假长 run；bbox 量高度比。
自报与复测差>0.02 打回。

## 素材库管理
全库打标(type/subject/suit/tm_risk/quality) → usage 对账捞未用 high 级 → 好素材必须用上。
样张按证明点归队(色准/解析/近摄/弱光/人像/街拍…)，一张图只能用一处。
品牌公开渠道(官网/YouTube BTS/问卷报告)是素材金矿：工厂片抽帧拼版、调研原声做引言墙。
B-roll 无字版管线：多窗版式母带先测亮窗静止区间，窗内裁 16:9 重切。

## 交付打包
- out-680 全量 + Figma 原生帧导出 = 「最终成品」文件夹(纯槽位号命名,无杂项)
- 「分类装配包」：每卖点一文件夹，文件名=序号_图示|实拍_内容说明_槽位号(按名排序即装配序)
- 退役帧移出并归档 audit/retired-*；待品牌清单随交付更新
