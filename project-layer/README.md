# 新项目起步清单（品类可替换层）

每个新品类项目开工前，替换/新填以下内容，通用骨架不动：

1. **品类附录**：仿 references/08-category-lens.md 重写——行业叙事弹药/证明形式惯例/专属红线/受众画像。竞品重新找(KS 搜同品类 Top 案例拆解证明形式)
2. **卖点顺序**：优先用品牌预热页顺序；无预热页则按五卖点漏斗自排
3. **project.json**：产品事实(锁定数字清单——本案教训:重量/价格/命名以品牌最新确认为准,旧稿数字是事故源)
4. **style-token 项目层**：色彩/字体/明暗配比(法则层直接继承模板)
5. **素材包盘点**：全库打标→product-plate 选图→缺口清单→品牌公开渠道挖料(官网/YouTube/问卷)
6. **待品牌清单**：授权/价格阶梯/背书/团队照/时间线费率——从第一天开始维护
7. **工作目录**：复制 codex/ 三件套到 Codex 工作目录,tutti 拉起双端
